brief description of DSN - Data Stream Network

Is a riftspace-based communication system that enables near-instant data transfer across vast distances. It connects to the Great Archive System, where information from probes, scout ships, and civilizations is stored and accessed. To use the network, a riftspace carrier signal is required, making the DSN the primary backbone for interstellar communication and knowledge sharing.
